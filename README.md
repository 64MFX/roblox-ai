# roblox-ui-references
A curated collection of Roblox UI references for Claude Code, Codex, and other AI coding assistants to study and use as design inspiration

## Contents
- `studs-ui/`, `sports/`, `Icons/`, `Animation-Refs/`: image and video references
- [`ui-styles/`](ui-styles/GUI-STYLES.md): 72 GUI styles, one folder each with a README, 60 credited preview images in 23 folders, palettes, Roblox recipes and references (credits in [IMAGE-CREDITS.md](ui-styles/IMAGE-CREDITS.md))
