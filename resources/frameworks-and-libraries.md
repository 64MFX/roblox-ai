# Frameworks and libraries

All links returned HTTP 200 on 2026-10-21. See the [resources index](README.md).

- [Knit](https://github.com/Sleitnick/Knit): Lightweight game framework (archived; read the README for status).
- [Flamework](https://github.com/rbxts-flamework/core): Decorator-based framework for roblox-ts.
- [Matter](https://github.com/matter-ecs/matter): Entity component system for Roblox.
- [Jecs](https://github.com/Ukendio/jecs): Fast ECS for Luau.
- [Planck](https://github.com/YetAnotherClown/planck): ECS scheduler/plugin system for Luau.
- [ProfileService](https://github.com/MadStudioRoblox/ProfileService): Session-locked DataStore wrapper (older).
- [ProfileStore](https://github.com/MadStudioRoblox/ProfileStore): Session-locked DataStore wrapper, successor to ProfileService.
- [Lapis](https://github.com/nezuo/lapis): DataStore abstraction with document-style API.
- [ReplicaService](https://github.com/MadStudioRoblox/ReplicaService): State replication from server to clients.
- [roblox-lua-promise](https://github.com/evaera/roblox-lua-promise): Promise implementation for Luau.
- [Janitor](https://github.com/howmanysmall/Janitor): Cleanup/maid object for connections and instances.
- [TopbarPlus](https://github.com/1ForeverHD/TopbarPlus): Topbar icon and menu builder.
- [ZonePlus](https://github.com/1ForeverHD/ZonePlus): Zone detection for players and parts.
- [Blink](https://github.com/1Axen/blink): IDL-based networking code generator for efficient remotes.
- [ByteNet](https://github.com/ffrostfall/ByteNet): Buffer-based networking library.
- [BridgeNet2](https://github.com/ffrostfall/BridgeNet2): Networking library with buffer serialization.
- [Fusion](https://github.com/dphfox/Fusion): Reactive UI library.
- [react-lua](https://github.com/jsdotlua/react-lua): Community React port for Luau.
- [Reflex](https://github.com/littensy/reflex): Redux-style state management.
- [Cmdr](https://github.com/evaera/Cmdr): Extensible command console.
- [Adonis](https://github.com/Epix-Incorporated/Adonis): Admin system and moderation tools.
- [RbxUtil](https://github.com/Sleitnick/RbxUtil): Utility modules (Signal, Trove, Timer, Tween helpers and more).
- [NevermoreEngine](https://github.com/Quenty/NevermoreEngine): Large module collection including Spring and UI helpers.
- [Iris](https://github.com/SirMallard/Iris): Immediate-mode GUI for debug tools.
