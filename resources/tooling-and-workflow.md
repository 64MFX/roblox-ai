# Tooling and workflow

All links returned HTTP 200 on 2026-10-21. See the [resources index](README.md).

- [Luau](https://luau.org/): Roblox's typed Luau language: syntax, type checking, performance guides.
- [Luau on GitHub](https://github.com/luau-lang/luau): Language implementation and issue tracker.
- [Rojo](https://rojo.space/): Sync a filesystem project into Roblox Studio so you can use Git and external editors.
- [Rojo (GitHub)](https://github.com/rojo-rbx/rojo): Source, releases and docs.
- [Wally](https://github.com/UpliftGames/wally): Package manager for Roblox.
- [Rokit](https://github.com/rojo-rbx/rokit): Toolchain manager for Roblox tools (Rojo, Wally, StyLua and more).
- [Aftman](https://github.com/LPGhatguy/aftman): Earlier toolchain manager, succeeded by Rokit.
- [Foreman](https://github.com/Roblox/foreman): Toolchain manager from Roblox.
- [StyLua](https://github.com/JohnnyMorganz/StyLua): Opinionated Luau code formatter.
- [Selene](https://github.com/Kampfkarren/selene): Luau linter.
- [luau-lsp](https://github.com/JohnnyMorganz/luau-lsp): Language server for Luau with Roblox type definitions; works in VS Code and other editors.
- [Lune](https://github.com/lune-org/lune): Standalone Luau runtime for scripts and tooling outside Roblox.
- [Darklua](https://github.com/seaofvoices/darklua): Transforms and bundles Luau code.
- [Remodel](https://github.com/rojo-rbx/remodel): Scriptable manipulation of Roblox place and model files.
- [Mantle](https://github.com/blake-mealey/mantle): Infrastructure-as-code for Roblox experiences.
- [Moonwave](https://github.com/evaera/moonwave): Documentation generator for Luau projects.
- [roblox-ts](https://github.com/roblox-ts/roblox-ts): TypeScript-to-Luau compiler.
- [roblox-ts site](https://roblox-ts.com/): Docs for roblox-ts.
- [Argon](https://github.com/argon-rbx/argon): Rojo alternative with its own Studio plugin.
- [jest-lua](https://github.com/jsdotlua/jest-lua): Jest port for Luau testing.
- [TestEZ](https://github.com/Roblox/testez): Roblox's BDD-style testing framework.
- [Roblox Studio MCP server](https://github.com/Roblox/studio-rust-mcp-server): Official MCP server that lets AI assistants drive Roblox Studio.
